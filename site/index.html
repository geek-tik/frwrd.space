Быстрый старт

Три шага до публичной ссылки на ваш локальный сервер.

  1. 1

    Запустите стек

    Скопируйте конфиг и поднимите сервисы:

    cp .env.example .env
make up
  2. 2

    Запустите локальный сервер

    Например, ваше приложение на порту 3000:

    npm run dev
# или любой сервер на localhost:3000
  3. 3

    Откройте туннель

    Агент в Docker пробросит порт с хоста:

    make tunnel PORT=3000
# → https://xxxx.frwrd.space
